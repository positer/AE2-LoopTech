# Loop Integrated CPU

<BlockImage id="ae2lpt:loop_integrated_cpu" scale="5" />
<RecipeFor id="ae2lpt:loop_integrated_cpu" />

Use the twenty slots to configure crafting storage and co-processors. Item cells provide their rated bytes. Fluid cells give one co-processor per 256 rated bytes. Loop cells and Quantum Omni cells contribute to both. Open the CPU status using the top-right tab or by sneak-right-clicking an active CPU.
