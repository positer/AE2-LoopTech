# 循环集成CPU

<BlockImage id="ae2lpt:loop_integrated_cpu" scale="5" />
<RecipeFor id="ae2lpt:loop_integrated_cpu" />

在二十个槽位中放入磁盘，配置合成存储和协处理器。物品磁盘提供等额的合成存储，流体磁盘每 256 字节提供一个协处理器。循环磁盘和 Quantum Omni 量子盘同时提供两项数值。放入一张无限循环存储磁盘即可获得无限合成存储和协处理能力。在线时可用右上角标签或潜行右键打开原生合成状态。
