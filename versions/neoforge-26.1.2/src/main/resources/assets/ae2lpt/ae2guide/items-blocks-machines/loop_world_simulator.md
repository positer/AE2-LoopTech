# Loop World Simulator

Put ingredients in the grid and fluid in the left tank. Products appear at the right.

Use **Active output** to enable or disable pushing products to adjacent machines, and **Output faces** to choose where products may leave. The simulator does not pull inputs. Redstone control can pause processing. Double-right-click a tank with an empty cursor to clear it.

The simulator is standalone. It does not join an ME network or require power. Automatic output only interacts with adjacent machines.
