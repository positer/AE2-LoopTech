# 循环世界合成模拟器

工作台合成使用指定的有序布局。

| 左 | 中 | 右 |
| --- | --- | --- |
| 铁锭 | 循环水晶 | 铁锭 |
| 放置面板 | 4k 循环存储核心 | 破坏面板 |
| 铁锭 | 元件工作台 | 铁锭 |

模拟器采用与超算接口一致的白色机框，是不接入 ME 网络、不需要 AE 或 FE 供电的独立机器。九个物品输入格接收无序的材料和引发物。默认每 20 个服务端刻结算一种可执行配方，份数取库存与输出空间允许的最大值。两种产物分别进入一个物品输出格和一个流体输出槽。每个流体槽的基础容量为 8,000 mB。界面沿用 AE2 分子装配室的底板、物品槽与进度组件。输入流体槽紧邻 3×3 原料区，输出流体槽位于物品产物格右侧；两个槽的上下边都与原料区对齐，液面表示当前容量占比。

左侧工具栏从上到下：

| 入口 | 设置与作用 |
| --- | --- |
| `?` | 打开循环世界合成模拟器的 GuideME 帮助。 |
| 主动输出 | 关闭（默认）或开启。开启后才会把两个产物槽的物品和流体送往相邻设备。机器不会主动拉取原料，仍可用管道被动输入。 |
| 允许输出面 | 在主界面左上浮层，按机器相对方向切换主动输出。蓝色为允许，灰色为禁止；同一配置作用于物品和流体。悬停显示相对方向与世界朝向。 |
| 红石控制 | 始终启用（默认）、有信号启用、无信号启用。不满足时暂停加工与主动搬运，但不会限制手动或被动操作。 |

六面始终可让相邻设备被动插入原料及抽取成品，不能抽取原料或者向成品槽插入。主动输出只通过允许的面，将物品和流体送至相邻设备的相应输入接口。接收方未接收的产物留在输出槽；不直接向 ME 网络导出。旧存档中的主动输出、输入输出两档迁移为开启，无、仅主动输入迁移为关闭。主动输出面保留，旧 ME 目的地和旧输入方向标志不再生效。物品产物格右侧使用 AE2 原生竖向进度条。机身正面的循环标识和状态条只在实际加工时变为绿色，不表示 ME 接入或供电。顶面沿用前屏的外框和深灰配色，在待机与加工时均保持无图案的素面。

右侧四个原生升级槽可混装加速卡和容量卡。

| 同类卡数 | 加速卡每轮周期 | 容量卡单槽倍率 | 单个流体槽 |
| --- | --- | --- | --- |
| 0 | 20 tick | 1 倍 | 8,000 mB |
| 1 | 10 tick | 2 倍 | 16,000 mB |
| 2 | 5 tick | 4 倍 | 32,000 mB |
| 3 | 3 tick | 8 倍 | 64,000 mB |
| 4 | 1 tick | 16 倍 | 128,000 mB |

物品槽以该物品的正常堆叠量为基数。拔掉容量卡会降低此后的入槽上限，槽里的现有物料可逐步取出。查看导入配方时，JEI 和 EMI 会显示材料、引发物和液体用量。1.21.1 使用 EMI 原版，26.1.2 支持 EMI - Port Forward。

| 已加载的世界交互 | 每份结算 |
| --- | --- |
| AE2 普通爆炸 | 消耗原生配方的材料和 1 个普通爆炸引发物。量子缠绕奇点输出一对同频奇点，单个输出格一次容纳一组频率。 |
| 循环科技无限磁盘 | 消耗 64 个 256M 循环存储核心、1 个循环存储组件外壳和 1 个普通爆炸引发物。 |
| AE2 浸入 | 消耗配方材料，将 1,000 mB 配方原液等量移至输出槽。原生福鲁伊克斯水晶配方使用水。 |
| Just Dire Things 流体转换 | 消耗催化物及 1,000 mB 源液，并输出 1,000 mB 目标液。时间水晶可将多态流体转换成时间流体。 |
| 闪电科技雷劈 | 使用原配方中心块及周边材料。保留避雷针与上游配方标记为保留的周边块。 |
| 闪电科技过载 TNT | 消耗 1 个过载 TNT 和闪电科技的彩蛋原料，产出已初始化的神秘元件。1.21.1 沿用闪电科技的开关与原料配置，26.1.2 沿用该代固定的闪电坍缩矩阵。 |

拿着装液容器左击输入流体槽即可注入。拿着空容器左击输出流体槽可取出液体。光标空着时，快速连续右击同一个流体槽两次可清空该槽，清空的液体不会转移到另一槽。满槽或输出中的类型冲突会暂停对应配方。即使没有可加工的配方，只要红石条件满足，主动输出也会继续清空产物。

## 配方导入配置

服务端配置文件为 `config/ae2lpt-world-simulator.toml`。默认自动导入已有适配器的配方。

```toml
automatic = true
allow = []
deny = []
```

`allow` 填写后只选择列出的配方。将 `automatic` 改为 `false` 可关闭默认导入，再通过 `allow` 手动选择。`deny` 优先。名单支持完整配方 ID、适配器的完整配方类型 ID，或形如 `justdirethings:*` 的配方命名空间。过载 TNT 的专用配方 ID 为 `ae2lt:overload_tnt_mysterious_cell`。常用的类型 ID 包括 `ae2:transform`、`justdirethings:fluiddroprecipe` 和 `ae2lt:lightning_strike`。数据包可扩展 `#ae2lpt:world_simulator_explosives` 标签，默认包含 TNT 和迷你 TNT。

## 双代验证

从仓库根目录用对应的 `build-<generation>.ps1 --offline -I (Resolve-Path tools/runtime-ripper-probe/probe.init.gradle) ripperProbeJar` 构建，再运行 `tools/runtime-ripper-probe/verify-background.ps1 -Generation <generation> -Chain world_simulator -EvidenceName ripper-world-simulator-<generation> -AdditionalMods <JDT 与闪电科技 JAR>`。为 1.21.1 的闪电科技同时提供其版本要求的 Thunderbolt Core。
