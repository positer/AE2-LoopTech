# 0.1.4 native release gate, 2026-11-27

## Production boundaries

- Minecraft 1.21.1 and 26.1.2 were built independently using their pinned AE2 and Java toolchains.
- In both generations the old Ripper inventory redirect competed with ExtendedAE Plus for the same AE2 call. Restrict the Ripper to its viewport at the first constructor storage of the resolved inventory instead. Ordinary and extended providers retain the inventory chosen by the prior call and keep their original slot addresses and behavior.
- Only 26.1.2 adds the optional Factory Editor EMI entry point. The native handler accepts one unambiguous item or fluid in the code area; an outside drop or an existing selection that cannot accept the complete identifier is not changed. It is not a required dependency and does not replace the existing JEI handler.
- The final 26.1.2 archive adds exactly two class entries (the optional EMI entry point and the handler). All 877 entries in the already-tested pre-EMI archive are byte-identical. The final dual-version fixture runs separate JEI and EMI profiles; a combined viewer profile is used to verify the World Simulator registration stays intact.

## Fixture maintenance

- Encoder removal is checked against the actual single clicked position, same-type bulk targets, and a different-type survivor. Redstone fixture tests use real transitions; new or changed programs restart whereas unchanged programs resume. Tests retain exact item/FE/chemical conservation and distinguish physical deliveries from running-job metadata.
- The test-only terminal selector supports both generations without modifying the main full profile. For the modern isolated viewer fixture the caller supplies the already-tested local NeoForge snapshot explicitly. The fixture acknowledges a warning only if NeoForge itself supplies the native Continue button; fatal loading screens are not bypassed.
- Capture and acceptance evidence record actual source locations, SHA-256, normal shutdown, and the original development mod manifest restoration when staging is required. Read the local release coverage report for the exact native suite matrix, split full/tail evidence, proven inherited state, and unsupported optional addon combinations. Do not infer that all results came from one uninterrupted run or that every third-party addon was tested.
